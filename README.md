# 🌡️ IoT Cloud Telemetry Pipeline

A college mini-project demonstrating a **cloud-native IoT data pipeline** —
edge devices stream sensor readings to Supabase, and a real-time Streamlit
dashboard visualises the data.

---

## Architecture

```
┌─────────────────────┐        REST/HTTPS        ┌──────────────────────┐
│  Device Simulator   │ ──────────────────────►  │  Supabase (Postgres) │
│  app.py             │   POST /device_telemetry  │  device_telemetry    │
│  3 virtual nodes    │                           │  table               │
└─────────────────────┘                           └──────────┬───────────┘
                                                             │  GET (SELECT)
                                                  ┌──────────▼───────────┐
                                                  │  Streamlit Dashboard │
                                                  │  dashboard.py        │
                                                  │  localhost:8501      │
                                                  └──────────────────────┘
```

---

## Features

### Simulator (`app.py`)
- Simulates **3 independent edge nodes** (EDGE-NODE-01/02/03), each with its own realistic temperature/humidity baseline
- **Automatic status codes**: `OK` · `WARN_TEMP` · `WARN_HUMIDITY` · `WARN_DRY` · `CRITICAL_TEMP`
- **Anomaly injection** — 5% chance of a spike reading per cycle to trigger alerts
- **Graceful shutdown** on Ctrl+C or SIGTERM
- Configurable push interval via `--interval` argument

### Dashboard (`dashboard.py`)
- **Live KPI metrics** with delta indicators (vs previous reading)
- **Alert banners** — critical/warning highlighted automatically
- **Per-device snapshot cards** showing latest reading and status
- **Interactive line charts** (temperature, humidity, dual-axis combined) via Altair
- **Device filter** in sidebar — select one or more nodes
- **Auto-refresh toggle** (10-second polling)
- **Paginated data ledger** with formatted columns

## Quick Start

### Option A — Run locally (no Docker)

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Start the simulator (terminal 1)
python app.py --interval 5

# 3. Start the dashboard (terminal 2)
streamlit run dashboard.py
# Open http://localhost:8501
```

### Option B — Docker Compose (both services)

```bash
docker compose up --build
# Dashboard → http://localhost:8501
```

## Supabase Schema

```sql
create table device_telemetry (
  id          bigint generated by default as identity primary key,
  created_at  timestamptz default timezone('utc', now()) not null,
  device_id   text    not null,
  temperature float8  not null,
  humidity    float8  not null,
  status_code text    not null
);
```

---

## Status Code Reference

| Code            | Meaning                          |
|-----------------|----------------------------------|
| `OK`            | All readings within normal range |
| `WARN_TEMP`     | Temperature > 33 °C              |
| `CRITICAL_TEMP` | Temperature > 36 °C              |
| `WARN_HUMIDITY` | Humidity > 80 %                  |
| `WARN_DRY`      | Humidity < 30 %                  |
